One Word, First Thought — a program that writes the first word that comes to mind, with no topic, no explanation and no second draft. It keeps the shortlist of words that actually surfaced, scores each on the judge's own brief (surprise, vividness, a spark of wit), and writes the winner — one bare word, nothing else — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

The program writes `apricity` — the warmth of the sun on a cold winter's day — to `/output/entry.txt` (8 bytes, no trailing newline).
